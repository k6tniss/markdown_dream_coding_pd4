# My Dream Coding Project: EcoTrack 

## Project Overview
**EcoTrack** is an app designed to help uusers *track their daily carbon footprint* and make small, sustainable choices that add up to a big impact. It's build using **HTML, CSS,** and **JavaScript** -- but one day. I want to expand it into a full web platform!

---

## Project Goals

- Build a user-friendly dashboard that tracks:
 
  - *Energy use*
  - *Transportation impact*
  - *Food consumption patterns*
- Display personalized reports using:

  - `console.log()` to debug process
  -
    ```
    if (carbonScore < 50) {
     console.log (Great job staying ecofriendly!");
    } else {
    console.log(Let's find ways to reduce your footprint!");
    }
    ```
